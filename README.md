## ✨ Key Capabilities

- 🧹 **Server Audits** — Roles, permissions, and bot safety checks  
- 🧠 **Clan Memory** — Member history, leadership notes, inactivity tracking  
- 🚨 **Command Authority** — Controlled leadership pings and actions  
- 🛡️ **Safety First** — No destructive permissions, no chaos  

---

## ⚔️ Command Arsenal

| Command | Description |
|------|------------|
| `/audit` | Server health & permission scan |
| `/whois` | Member snapshot |
| `/note` | Add leadership note |
| `/notes` | View member notes |
| `/inactive` | Inactivity report |
| `/ping mods` | Alert moderators |
| `/ping leaders` | Alert leadership |
